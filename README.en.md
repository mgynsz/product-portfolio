## Selected Products

### 01. Rangeon

**ML-enabled Crypto Market Analytics SaaS**

Rangeon started while I was working with long-term crypto market data through BotBlue and BotBlue Orbit.

While handling up to eight years of minute-level market data, I saw that there was plenty of market information, but fewer tools that helped users understand where their position stood in statistical context.

### Problem

Raw historical ranges were often too wide to be useful in practice.

I experimented with market indicators and derived features to separate meaningful signals from noise, then applied ML models to evaluate whether forecast ranges and expected movement could be made more useful while continuing to expose prediction error.

### Product Principle

Rangeon does not tell users to Buy, Sell, go Long, or go Short.

Instead, it visualizes the statistical context needed for users to make their own decisions.

The product includes:

- Forecast Range
- Expected Movement
- Statistical position of the current price
- Position Tracking
- Forecast Quality
- Historical forecast results and quality metrics

Forecast quality is continuously evaluated and exposed to users rather than hidden behind a simple accuracy claim.

### 02. Kivvo

**Adaptive Learning Platform for Memory Management**

Kivvo treats forgetting as a natural part of learning rather than a failure.

Users review custom learning content through short Play sessions. When recall is uncertain, they can hold to gradually reveal a hint.

The system uses response time, hold duration, hint usage, and repeated outcomes to estimate Memory Status and Memory Strength and adjust the next review timing.

### Core Concepts

- Memory Status
  - `new`
  - `at-risk`
  - `fragile`
  - `mastered`
- Memory Strength
- Adaptive Review Interval
- Forgetting-based Memory Decay
- Personal Learning Rhythm
- CSV Vocabulary Import / Export
- Personal Dashboard
- Group / Admin Dashboard

### Current Status

- Product / UX Design complete
- Frontend near completion
- Data Model designed
- Backend / Algorithm next

> Source code remains private while the product is under development.
